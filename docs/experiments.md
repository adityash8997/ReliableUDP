# Experiments and Analysis

This project includes the foundations for the required experiments, but the actual protocol algorithms and experiment execution remain future phases.

## Planned experiments

1. Goodput versus loss rate
2. Goodput versus window size
3. Retransmissions versus reordering probability
4. RTO sensitivity analysis

## Required methodology

- record independent variables
- record dependent variables
- keep controlled variables fixed
- repeat experiments to reduce variance
- store raw output separately from analyzed results
