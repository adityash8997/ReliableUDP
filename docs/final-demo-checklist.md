# Final Demo Checklist

1. Explain the problem and why UDP requires reliability.
2. Explain the architecture and protocol boundary.
3. Explain the custom packet format and checksum.
4. Start the receiver side.
5. Transfer a file under clean conditions.
6. Show integrity verification.
7. Introduce packet loss.
8. Show retransmission behavior and timeout handling.
9. Compare protocol behavior across the supported protocol stubs.
10. Show metrics and experimental output.
11. Show one graph from the generated plots.
12. Explain the graph and the networking concept behind it.
13. Demonstrate deterministic seed behavior.
14. Explain a failure case and how the invariant would catch it.
15. Answer viva questions based on the implementation.
